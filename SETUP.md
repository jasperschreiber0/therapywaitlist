# TherapyWaitlist — Launch Checklist

Everything that can be done in code is done. Below is what requires your credentials or accounts.

---

## 1. Get API keys (5 minutes)

### Anthropic
1. Go to console.anthropic.com → API Keys → Create key
2. Copy it as `ANTHROPIC_API_KEY`

### Resend
1. Go to resend.com → Create account
2. Add and verify your domain (add a DNS TXT record — takes ~10 min to propagate)
3. Create an API key → copy as `RESEND_API_KEY`
4. Update `from:` in `backend/src/services/notifications.js` and `backend/src/jobs/freshnessPrompt.js` to use your verified domain

---

## 2. Deploy on Render (recommended — free tier available)

1. Push this repo to GitHub
2. Go to render.com → New → Blueprint → point at your repo
3. Render reads `render.yaml` and creates:
   - A PostgreSQL database
   - The backend web service
   - The frontend static site
4. Set these env vars in Render dashboard (under the backend service):
   - `ANTHROPIC_API_KEY` — from step 1
   - `RESEND_API_KEY` — from step 1
   - `FRONTEND_URL` — the Render URL of your frontend (e.g. `https://therapywaitlist-frontend.onrender.com`)
   - `ADMIN_EMAIL` — where staleness alerts go (e.g. your email)
5. `JWT_SECRET` and `ADMIN_API_KEY` are auto-generated by Render — note them down from the dashboard

---

## 3. Run the database migration

After the backend is deployed and the database is provisioned:

```bash
# From your local machine with the DATABASE_URL env var set
DATABASE_URL=<your-render-postgres-url> bash backend/prisma/migrations/migrate.sh
```

This runs `prisma migrate deploy` + seeds the 5 Eastern Suburbs demo clinics.

---

## 4. Get your admin API key

The `ADMIN_API_KEY` env var is your password to the admin panel at `/admin`.

Log in at: `https://your-frontend-url.onrender.com/admin/login`

---

## 5. Generate a clinic dashboard token for your first clinic

Clinic admins access their dashboard via a token in their email links (generated automatically by the weekly freshness prompt). To manually generate one for testing:

```bash
curl -X POST https://your-backend-url.onrender.com/api/clinic/auth/token \
  -H "Content-Type: application/json" \
  -d '{
    "clinic_id": "<uuid from database>",
    "email": "<clinic admin email>",
    "admin_key": "<your ADMIN_API_KEY>"
  }'
```

The response contains a `token` — use it as `Authorization: Bearer <token>` or open:
`/clinic/<clinic_id>/dashboard` with the token stored in localStorage as `clinic_token`.

---

## Local development

```bash
# 1. Copy env
cp .env.example .env
# (fill in your API keys)

# 2. Start PostgreSQL (Docker)
docker compose up db -d

# 3. Run migration + seed
cd backend && DATABASE_URL=postgresql://tw_user:tw_dev_password@localhost:5432/therapywaitlist npx prisma migrate deploy && node prisma/seed.js

# 4. Start backend + frontend
cd .. && npm run dev
```

Backend: http://localhost:4000  
Frontend: http://localhost:3000  
Admin panel: http://localhost:3000/admin
